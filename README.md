# 买房 VS 租房 / 卖房 VS 留房 决策计算器

**在线体验**：https://housing-decision-calc.vercel.app

三个纯前端的个人财务决策计算器，不含后端、不含数据库，所有计算都在浏览器本地完成。

| 页面 | 文件 | 回答的问题 |
|---|---|---|
| ① 未购房 | `index.html` | 买房划算还是租房划算？买房者可以自己选第几年买房，首付不够可以借钱买。 |
| ② 已购房 | `sell-vs-hold.html` | 房子跌了，卖掉重开始还是留着继续还贷？三条路径：卖出 / 留房自住 / 留房出租。 |
| ③ 人生规划 | `life-plan.html` | 从当前现金、投资和负债出发，工作、提前退休、社保公积金、买房、买车等大件怎么影响未来 60 年？ |

三个页面顶部有导航栏可互相跳转。

## 特点

- **单文件**：每个页面都是自包含的 HTML，内联 CSS/JS，ECharts 走 CDN，双击即可打开，不需要构建工具。
- **实时计算**：改任意输入框立刻重算结论、走势图、逐年收支明细。
- **桌面端吸顶参数面板**：滚动查看结论和明细时参数一直留在左侧；底部可一键恢复默认参数。
- **口径写清楚**：每条结论都能在页面上追到公式——等额本息/等额本金的推算过程、装修费的负债规则、期末"手上的现金"到底算了什么。
- **不藏假设**：模型没算什么（房价预测、维修翻新、三阶段之外的大额医疗养老支出）都在页面上列出来。

## 模型口径摘要

页面一、页面二的核心指标统一是**第 N 年末手上的现金**，而不是账面净资产；页面三看的是包含存款、公积金和自住房估值的**期末净资产**。

### 共同规则

- 存款按年化利率（默认 1.3%）按月复利，仅对正余额计息，无利息税。
- 现金为负且存款不足时记为透支欠款，欠款不计息不复利，**正现金流先还欠款**。
- 收入、生活开销、水电燃气取暖是页面一/二中同一个人多条路径的共同项。
- **人生三阶段是共同事件**：工作期 → 提前退休期（无工资无养老金）→ 领养老金期，三个页面用同一套年龄口径。到达各阶段起始年龄后收入与生活开销同步切换。

### 页面一（买房 vs 租房）

- **对比周期固定 60 年**，走势可以看到第 60 年末。
- **购房年份是独立输入框**（第 1～60 年，默认第 10 年）：房子第几年买由你决定，不再等"攒够首付"才买。
- **不限制购房时的自有资金**：首付 + 税费一次付清，付不出来的部分自动记为负债（不计息、不复利），可以真实模拟"借钱买房"。
- **收入分三个阶段**（"个人与理财参数"里用三个子框分组），阶段用**年龄**表示：
  - ① **工作期**：有工资，无养老金。
  - ② **提前退休期**：**没有工资也没有养老金**，生活开销全部从已有存款里扣（先吃利息，再吃本金，存款不够就变负债）。
  - ③ **领养老金期**：有养老金，无工资。
  - 以「当前年龄」为锚点：当前 25 岁 → 第 1 年；55 岁提前退休 → 第 31 年；65 岁领养老金 → 第 41 年；期末为 84 岁。
  - 三个阶段各自填一份"每月其他生活开销"；年龄填 0 表示该阶段不启用。阶段划分对买房者和租房者是同一个人的共同事件。
- **期末默认不卖房**（自住到期末），房产估值不计入现金；可一键切换为期末卖房。
- 购房前买房者与租房者收支完全相同；页面会标出购房当年末负债和周期内最大负债。
- 装修费按还款年限**无息分期**偿还；翻新费在指定年份（默认为购房后第 30 年末）计入现金流。

### 页面二（卖房 vs 留房）

- 沉没成本隔离：已付首付、已还本金只用于展示"账面浮亏"，不参与计算。
- 已还本金与剩余贷款本金由等额本息/等额本金公式自动推算，不用手填。
- 卖房时立刻结清剩余贷款：卖房净得 = 市值 × (1 − 增值税 − 个税 − 中介费) − 剩余贷款。
- 路径 C 的出租收入与自住租金是**两个独立参数**（早期版本复用了同一个参数，导致路径 C 退化成路径 B）。
- **三阶段收入模型**与页面一相同：工作期（有工资）、提前退休期（无工资无养老金，开销吃存款）、领养老金期（有养老金）。默认当前 30 岁、55 岁提前退休、65 岁领养老金 → 第 1 / 26 / 36 年，期末 89 岁。
- 三阶段各自有一份"每月其他生活开销"；年龄填 0 表示该阶段不启用。页面额外给出**各阶段每月结余表**，贷款在阶段中途还清时会拆成"还贷中 / 还清后"两行。
- 对比期末三条路径都不卖房，指标是手上的现金；留房路径的房产与剩余贷款相互抵消，作为参考信息单独显示。
- 走势图标注提前退休与领养老金年份，横轴每 10 年显示一次"年份/年龄"；逐年明细增加"年龄""阶段"两列。
- 左侧参数面板在桌面端吸顶显示，底部有"恢复默认参数"按钮。

### 页面三（人生现金流规划）

- **两个钱包**：当前资产分成"现金钱包"（活期/零钱通，默认 0.7%）和"投资钱包"（期望收益，默认 5%，实际会波动）。每月结余先还负债，再按比例分到两个钱包；支出不够时先花现金钱包，再花投资钱包，最后才形成负债。
- **投资不是稳定收益**：投资钱包按期望收益率计算，另用"收益率上下浮动"给出保守/基准/乐观三个情景；图上按基准画，结果区同时显示三个情景的期末投资钱包和净资产。
- **起点可调**：当前年龄、当前现金、当前投资、当前负债、负债年利率都可以改，不是从零开始。
- **人生三阶段**：工作期 / 提前退休期 / 领养老金期，三个阶段各有一份月收入和月生活开销；养老金是手填假设值。默认当前 28 岁、55 岁提前退休、65 岁领养老金 → 第 28 / 38 年，期末 87 岁。
- **社保与公积金**：可分别勾选"缴纳社保 / 缴纳公积金"；月薪按税前口径填，页面会实时显示"税前 − 社保个人 − 公积金个人 ≈ 到手"的拆解。社保个人部分扣掉后不形成资产；公积金个人 + 单位缴纳都进入公积金账户并按公积金利率计息，期末计入净资产；购房时可选优先用公积金余额支付首付和税费。
- **买房可启停**：住房方案是一个可勾选/取消的独立模块，不启用时整个页面按"一直租房"计算。启用后计算首付、税费、房贷、物业费；买房前和租房时付租金。用"房产年增值率"估算自住房期末估值，并同时给出继续持有和卖房扣成本两个净得口径；启用买房时会自动再跑一次"不买房"方案做同参数对比。
- **大件支出**：支持动态添加多项（买车、装修、婚礼等），每项可设金额、年份、首付比例、分期年数和分期利率；金额填负数表示一次性收入。
- **现金流细节**：当前负债和透支欠款按负债利率计息，正现金流优先还债；每年明细列出社保、公积金个人/单位、生活、房租、房贷、物业、水电、大件、购房、现金利息、投资利息、公积金利息、净资产等。
- 右侧图表是**资产构成堆叠图**：橙色=现金钱包、蓝色=投资钱包、紫色=公积金、灰色=自住房估值，深绿色线=净资产；图下方有颜色说明，避免分不清哪条线是什么。

## 部署到 Vercel

线上地址：**https://housing-decision-calc.vercel.app**

### 方式一：GitHub 导入（推荐，也是本项目采用的方式）

1. 把本仓库推到 GitHub
2. 打开 [vercel.com/new](https://vercel.com/new)，用 GitHub 账号登录
3. 选择该仓库，Framework Preset 选 **Other**
4. Build Command 留空，Output Directory 填 `.`
5. Deploy

仓库是纯静态站点，Vercel 会直接托管 HTML，无需构建。

### 方式二：命令行

```bash
npm i -g vercel
vercel            # 首次会引导登录
vercel --prod     # 部署到生产环境
```
