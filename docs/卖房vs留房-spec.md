# 卖房 vs 留房 决策模型（完整提示词 / 建模规范）

> 对应实现：`sell-vs-hold.html`。与 `index.html`（买房 vs 租房）通过导航栏互跳。
> 样式与工程约定沿用 `房租对比-完整建模提示词.md`，不再重复。

## 1. 目标

服务于**已经买了房**的房主：房子已贬值、首付已付、贷款还了一部分，现在要决定**卖掉换现金**还是**留着继续还贷**。

三条路径：

| 路径 | 说明 |
|---|---|
| A 卖出 | 卖掉变现，拿到现金，从此租房生活，现金按存款利率复利累积 |
| B 留房自住 | 继续还贷、继续自住，月末结余存入银行 |
| C 留房出租 | 房子租出去收租，自己另租小房住 |

## 2. 核心口径

1. **这是"从今天起"的决策。** 已付首付和已还本金是沉没成本，只在页面展示"账面浮亏"，不参与任何计算。
2. **期末口径：手上的现金。** 对比期末三条路径都不卖房，指标统一为"手上到底有多少现金"：
   - 手上现金 = 年末存款 − 透支欠款
   - **房产价值与剩余贷款都不计入。** 对留房路径而言，房子还在、贷款也还在，两者相互抵消；若只算现金不记负债会造成单边惩罚。
   - 留房路径仍持有的房产（按当前市值）与剩余贷款作为**参考信息**单独显示，不进主指标。
3. **不预测未来房价。** 模型不设期末房价输入，因此没有"临界房价"这类结论。留房路径的房产只按当前市值作参考，并注明"若现在卖能净剩多少"。
4. **对比周期固定 60 年**，不做成输入项，页面上以固定值展示。
5. **卖房净得** = 当前市值 × (1 − 增值税% − 个税% − 中介费%) − 剩余贷款本金。市值低于剩余贷款时为负数，即卖房也还不清贷款，差额转为透支欠款。
6. **三条路径的共同项相同**：收入、生活开销、水电燃气取暖、存款利率。
7. **退休是共同事件。** 退休时间是同一个人的人生节点，三条路径完全一致：从第 R 年起（默认第 36 年，即 35 年后退休），工作收入停止，改为每月领取退休工资（默认 3000 元）。其余月份仍按工作收入计算。
7. **路径 A 卖房后按"卖出后自住月租金"租房**，垫付押金（押金月数 × 月租金），期末退回；第 1 个月另计搬家过渡成本。
8. **路径 C（留房出租）**：房子出租出去，自己另租小房住。**出租收入与自住租金必须是两个独立参数**——早期版本让路径 C 复用"卖出后自住月租金"，导致出租收入与自住租金几乎抵消，路径 C 退化成路径 B，属于建模缺陷。
   - 实际出租收入 = 出租月收入 × (1 − 出租空置率%)
   - 房东承担：物业费、维修预留、月供
   - 租客承担：租金、房屋水电
   - 自己承担：另租小房的租金、自己住处的水电、生活开销
   - 另租房押金按押金月数 × 自住租金计算，期末退回
   - 出租收入不得再扣物业或维修，否则与单独计列的持有成本重复计算
9. **房屋维修、未来翻新、房屋寿命都不进入计算。** 这三项在早期版本里是输入项，但会让参数表变得庞杂且难以判断影响，改为在页面上以纯文本提醒的形式列出。
   - 不计入每月维修预留（中修、大修、电梯与外墙更新等）
   - 不按年份预提翻新与装修支出
   - 不考虑房屋还能使用多少年、房龄折价、自然老化、拆迁
   - 页面"未计入的因素"卡片必须明确写出以上三项，并说明留房路径的真实持有成本高于页面数字
10. **存款与负债规则**：存款按月复利（默认 1.3%，无利息税），仅对正余额计息；月供等额本息按剩余本金、利率、剩余期限计算，不提前还贷；现金为负且存款不足时记为透支欠款，欠款不计息不复利，**正现金流必须先还欠款，还清后才转为存款**。
    - 这条曾经实现错误：现金流为正时没有先还欠款，导致欠款永久挂账、形成"免费钱"。手写资金分配函数时必须覆盖正负两个分支，不能只写"不够就记欠款"。
11. **不做"攒钱买回"等卖出后资金去向选项。** 页面聚焦"卖还是留"这一个决策。

## 3. 参数

**房产与贷款现状**：当前房屋市值、原始购房总价、原始首付比例、房贷年利率、还款方式（等额本息 / 等额本金）、已还贷款年限、剩余贷款期限、每月物业费。

**卖出侧**：增值税%、个税%、中介费%、卖出后自住月租金、押金月数、搬家过渡成本。

**共同项**：个人月收入、退休时间（从现在起第几年起退休）、每月退休工资、每月其他生活开销、每月水电燃气取暖、存款年化利率。对比周期固定 60 年。

**路径 C 专属**：出租月收入、出租空置率、自己另租的月租金。

### 3.1 推算规则（不手填）

已还本金与剩余贷款本金由输入自动推出，页面不提供输入框。**推算方式随还款方式而变**：

**等额本息**（月供固定）：

1. 原始首付 = 原始购房总价 × 首付比例
2. 原始贷款 = 原始购房总价 − 原始首付
3. 总贷款期数 = (已还贷款年限 + 剩余贷款期限) × 12
4. 月供 = 原始贷款 × 月利率 × (1+月利率)^总期数 ÷ [(1+月利率)^总期数 − 1]，月利率 = 年利率 ÷ 12
5. 剩余本金 = 原始贷款 × (1+r)^k − 月供 × ((1+r)^k − 1)/r，k = 已还贷款年限 × 12；r = 0 时为 原始贷款 − 月供 × k
6. 已还本金 = 原始贷款 − 剩余本金

**等额本金**（每月还本固定、月供递减）：

1. 原始首付、原始贷款、总贷款期数三步同上，但月供改为：每月还本 = 原始贷款 ÷ 总期数
2. 剩余本金 = 原始贷款 × (1 − 已还期数 ÷ 总期数)
3. 已还本金 = 原始贷款 − 剩余本金
4. 每月月供 = 每月还本 + 当期剩余本金 × 月利率，逐月递减

两种方式下余额滚动统一用 `余额 = 余额 × (1+r) − 当期月供`：等额本金代入后自动等于 `余额 − 每月还本`，无需另写分支。

因为月供是按总期数算的，用它摊还剩余期数恰好把贷款还清，所以"剩余本金 + 剩余期限 + 利率"反推的月供与原月供一致，模型自洽。页面需展示推算结果、公式说明，以及逐年还款计划表（期初剩余本金、当年月供合计、其中利息、其中本金、期末剩余本金）。

## 4. 输出

1. **结论**：第 N 年末三条路径的手上现金，以及最优路径与差额。
2. **每月收支表**（结论框内，标题"每月收支（元）· 贷款还清前"）：三列对应 A/B/C，逐行列出月收入、租金、出租收入、房贷月供、物业费、水电燃气取暖、生活开销，末行是月结余（正数红、负数绿）。不适用项显示"—"。表下附说明，包含：
   - 退休后（第 R+1 年起）月收入降为退休工资
   - 贷款还清后的月结余（工作期）
   - 退休后（贷款已还清）的月结余
   - 若退休时贷款尚未还清，额外给出"退休后仍需还贷"的月结余并加醒目提示
   - 房贷月供的首月利息与本金拆分、整个贷款期的累计还本与付息
3. **三张路径卡**：手上现金、路径说明；留房路径额外显示"仍持有房产（当前市值，未计入现金）""剩余贷款""现在卖出净剩"；存款与透支欠款分列。
3. **未计入的因素（提醒）卡片**：纯文本列出房屋维修费用、未来翻新与装修费用、房屋使用寿命与房龄折价、房价不预测四项，说明留房路径真实持有成本更高。
3. **房贷还款计划（按年）**：还款方式公式说明（随所选方式切换）、逐年摊还表、合计行的总月供/总利息/总本金/期末余额。
4. **手上现金走势**：三条折线，按年。
5. **关键判断**：
   - 原始贷款总额、原始首付（推算）、月供（推算）、已还本金（推算）、剩余贷款本金（推算），并附推算公式说明
   - **每月房贷月供**（等额本金标"首月"），及首月的利息/本金拆分、整个贷款期的累计还本与付息
   - 已投入、当前净值、账面浮亏（标注沉没成本）
   - 现在卖房净回笼
   - 留房路径当前月供与每月结余、卖出路径每月结余
   - A/B 与 A/C 交叉点
   - **临界自住租金**：对卖出后月租金做二分搜索，找到 A 与 B 手上现金相等时的租金；无解时标注。
   - **口径提示**：当最优路径是 B 或 C 时，必须额外显示醒目提示——留房路径胜出建立在"房产不计入现金"的前提上，不用付 60 年房租是优势来源，而房价涨跌完全不进账；若房价继续跌，留房优势会缩水甚至反转。
6. **期末成本拆解**：三条路径横向对照，末行为期末手上现金。不含维修、翻新行。
7. **每年收支明细**：三张表，每行一年，列出收入、租金、出租收入、月供、物业、水电、生活、一次性支出、存款利息、年度结余、年末存款、透支欠款、剩余贷款、手上现金。
8. **页面底部说明**：沉没成本、期末口径（不卖房）、不预测房价、交易成本估算提示、未计入因素提示。

## 5. 校验要求

- **沉没成本隔离**：改变"原始购房总价 / 原始首付 / 已还本金"不应改变任何计算结果。
- **现金口径自洽**：手上现金 = 年末存款 − 透支欠款，路径卡、成本拆解表、年度明细末行三者必须一致。
- **欠款必须能还清**：当某条路径出现透支后，后续正现金流必须逐月冲减欠款，欠款在有限时间内归零；不能出现"欠款永远挂账、存款却照常累积"的情况。检验方法：把月收入调到现金流为负（如 6000 元），再调高，应能看到欠款归零且之后存款正常增长。
- **退休切换点**：年度明细中第 R 年收入为工作月收入 × 12，第 R+1 年为退休工资 × 12，切换必须发生在正确年份。
- **退休为共同事件**：三条路径的收入切换必须在同一年发生；退休后各路径之间的月结余差额应保持不变（因为退休对每条路径的影响相同）。
- **推算自洽**：把已还年限设为 0 时，剩余本金应等于原始贷款、已还本金为 0；利率为 0 时，月供 = 原始贷款 ÷ 总期数，已还本金 = 原始贷款 ÷ 总年数 × 已还年数。
- **摊还一致**：用"剩余本金 + 剩余期限 + 利率"反推的月供，必须与"原始贷款 + 总期限 + 利率"算出的月供相等。
- **路径 C 独立性**：改变"自己另租的月租金"只影响路径 C；改变"出租月收入"只影响路径 C。
- **路径 C 上下界**：出租收入为 0 时路径 C 应劣于路径 B；自住租金为 0 时路径 C 应明显优于路径 B。
- **交叉点合理性**：若 B 路径的月现金流长期为负，A 应从第一年就领先且无交叉点。
- **负资产**：市值低于剩余贷款时应给出警告，且三条路径均出现透支欠款。

## 6. 非目标

- 收入、租金、物业费的年增长率。
- 未来房价预测、期末变现、临界房价分析。
- 退休后的消费习惯变化、医疗与养老支出、社保养老金调整、通货膨胀（仅页面提醒，不计算）。
- 房屋维修费用、翻新费用、房屋使用寿命与房龄折价（仅页面提醒，不计算）。
- 卖出后重新攒钱买回。
- 卖房后剩余贷款由买方承接等特殊交易安排。
- 出租路径中出租收入的逐年变化、家具折旧。
- 二手房交易中"满二/满五唯一"的自动判定（按用户输入的百分比处理）。
- 户口、入学、居住稳定性等非财务因素。
