# 人生现金流规划（完整建模规范）

> 对应实现：`life-plan.html`。与 `index.html`（买房 vs 租房）、`sell-vs-hold.html`（卖房 vs 留房）通过导航栏互跳。
> 本页是单人长周期现金流推演（规划年数默认 60 年，可改），不比较"两条路线"，而是把当前资产、收入阶段、社保公积金、住房选择和大件支出放进同一条时间线。

## 1. 目标

回答这类问题：**以我现在的现金、投资、负债和收入，如果第几年买房、中间买车/装修，社保公积金照缴，规划期末手里大概有多少钱？**

页面支持：

- 当前现金钱包、当前投资钱包、当前负债、负债利率作为起点。
- 工作期 / 提前退休期 / 领养老金期三阶段收入与生活开销。
- 社保个人缴纳、公积金个人 + 单位缴纳、公积金账户余额与利息。
- 住房方案可启停：启用后可设第 N 年买房，未启用按一直租房。
- 动态添加多项大件支出（买车、装修、婚礼等），支持一次付清或分期。
- 现金钱包和投资钱包分开计息；投资钱包用"期望收益率 ± 上下浮动"给出保守/基准/乐观情景。
- 期末同时给出"继续持有房产"和"卖房扣交易成本"两个净资产口径。

## 2. 核心口径

1. **起点不是零。** 第 0 年现金钱包 = 当前现金，投资钱包 = 当前投资，公积金 = 当前公积金余额，负债 = 当前负债。第 0 年净资产 = 现金 + 投资 + 公积金 − 负债。
2. **逐月模拟，周期为规划年数 N（默认 60 年，可改）。** 第 1 年对应月份 1..12，第 n 年对应 `(n−1)×12+1 .. n×12`。
3. **三阶段用年龄表示。** 当前年龄对应第 1 年；第 A 岁落在第 `(A − 当前年龄 + 1)` 年，起始月 = `(A − 当前年龄) × 12 + 1`。阶段 2/3 年龄填 0 表示不启用。
4. **工作期才有工资、社保和公积金。** 阶段 2 无工资无养老金，生活开销从两个钱包里扣；阶段 3 只有养老金，不缴社保公积金。养老金是手填假设值，不按缴费年限自动推算。页面提供"缴纳社保 / 缴纳公积金"开关，取消勾选即视为不缴。
5. **社保个人缴纳是支出，不形成资产。** 社保个人缴纳 = 工资 × 社保个人比例，只在阶段 1 且已开始工作时计列；单位缴纳部分不进入个人现金流。
6. **公积金个人 + 单位缴纳都进入公积金账户。** 公积金账户按公积金年利率按月计息；购房时可选优先用公积金余额支付首付和税费；期末公积金余额计入净资产。取消"缴纳公积金"后不再有新缴存，已有余额仍计息。按《住房公积金管理条例》和各地公积金中心口径，离休、退休可一次性提取账户全部余额并销户；页面可选择"开始退休时 / 领养老金时 / 不提取"，提取时余额转入现金钱包。
7. **住房是选项。**
   - 一直租房：每月付租金 + 水电 + 生活开销（生活开销不含房租水电，下同），不产生房贷和物业费。
   - 第 M 年买房：购房发生在第 M 年末（月份 M×12）。购房前付租金；购房当月付首付 + 税费（可先用公积金余额）；贷款 = 总价 − 首付；从购房次月起按月等额本息还款，同时开始付物业费；购房后不再付租金。
   - 自住房按"房产年增值率"逐年估值；期末卖房时按"期末卖房交易成本"扣减。
8. **大件支出是动态列表。**
   - 金额 > 0 且分期年数 = 0：第 N 年末一次付清。
   - 金额 > 0 且分期年数 > 0：第 N 年末付首付，剩余部分从次月起按等额本息分期，利息计入成本。
   - 金额 < 0：第 N 年末按一次性收入处理（如卖旧车、家人资助），不做分期。
9. **资金分配规则（两个钱包）。** 每月先还负债、支付各项支出；然后从现金钱包按**当前阶段**的"每月投入投资"固定金额转入投资钱包（现金不够就只转能拿出的部分），剩余留在现金钱包。现金流为负时先取现金钱包，再取投资钱包，仍不足的部分形成负债。现金钱包按现金利率、投资钱包按投资收益率、公积金按公积金利率、负债按负债利率分别按月滚动。
10. **期末净资产 = 现金钱包 + 投资钱包 + 公积金 + 自住房估值 − 负债 − 房贷余额 − 大件分期余额。**
11. **年度现金流**（用于年度明细）= 收入 + 单位公积金 + 现金钱包利息 + 投资钱包收益 + 公积金利息 − 社保 − 生活开销 − 房租 − 房贷月供 − 物业费 − 水电燃气取暖 − 大件支出 − 购房首付税费 − 负债利息。
    - 个人公积金是工资到公积金账户的内部转移，不计入年度现金流；单位公积金是额外进入公积金账户的钱。
12. **投资钱包不是稳定收益。** 主结果按期望收益率计算；另用"期望收益率 ± 上下浮动（百分点）"跑保守/乐观两个情景，分别展示期末投资钱包和净资产。区间只是两端固定年化假设，不代表真实波动路径。
13. **不考虑通货膨胀、工资增长、租金上涨、房屋维修与翻新。** 所有收入、租金、开销都是固定值；维修/翻新如需考虑，请手动添加为大件支出。

## 4. 计算逻辑

### 4.1 每月顺序

对 t = 1..规划年数×12：

1. 判定阶段，得到月收入 `inc`、月生活开销 `liv`、是否处于工作期。
2. 现金钱包计息：`cash += cash × 现金月利率`；投资钱包计息：`invest += invest × 投资月利率`。
3. 公积金计息：`fund += fund × 公积金月利率`。
4. 负债计息：`debt += debt × 负债月利率`。
5. 工作期社保/公积金：`social = 税前月薪 × 社保比例`，`fundP = 税前月薪 × 公积金个人比例`，`fundE = 税前月薪 × 公积金单位比例`；`fund += fundP + fundE`。
6. 公积金退休提取：若当前月等于所选提取时点，`cash += fund`，`fund = 0`；这是钱包内部转移，不计入年度现金流。
7. 房租支付：若启用"房租优先用公积金余额"且当月有房租，先从公积金余额扣 `min(fund, 房租)` 并转入现金钱包，剩余房租再从现金扣；公积金支付部分计入 `fundUsedRent`，属于内部转移，不计入年度现金流。
8. 房贷：购房次月起，按等额本息还款，利息 = 剩余本金 × 房贷月利率；最后一个月强制还清剩余本金。
9. 大件分期：购买次月起还款；最后一个月强制还清剩余本金。
10. 购房月：`首付 + 税费` 先从公积金余额扣（若启用），剩余从现金钱包 → 投资钱包扣；仍不足的部分形成负债；贷款余额 = 总价 − 首付。
11. 计算当月现金流：
   `flow = inc − social − fundP − liv − 房租 − 房贷 − 物业 − 水电 − 大件支出 − 购房现金支出 + 大件负值收入`
12. 资金分配：先把当月现金流按"正数先还负债、剩余进现金钱包；负数先取现金钱包、再取投资钱包、仍不足形成负债"处理；然后从现金钱包按当前阶段的"每月投入投资"固定金额转入投资钱包（最多不超过现金余额），剩余留在现金钱包。
13. 投资收益率情景：主结果用期望收益率；另用 `期望收益率 − 上下浮动` 和 `期望收益率 + 上下浮动` 各跑一次，得到保守/乐观的期末投资钱包和净资产。

### 4.2 阶段判定

- 阶段 3 优先：`t ≥ 领养老金起始月` → 阶段 3。
- 阶段 2 次之：`t ≥ 提前退休起始月` → 阶段 2。
- 否则阶段 1。
- 早于开始工作月：无收入、无生活开销、无社保公积金。
- 阶段顺序颠倒（p2 > p3）时以更早的边界为准，阶段 2 被跳过。

### 4.3 年度快照

每年末记录：

- 收入、社保、公积金个人/单位、生活、房租、房贷、物业、水电、大件、购房、公积金提取、现金利息、投资利息、公积金利息、负债利息。
- 年度现金流、年末现金钱包、年末投资钱包、年末公积金、年末负债、房贷余额、大件分期余额、房产估值、净资产。

其中净资产：

`cash + invest + fund + houseValue − debt − mortgageBal − installmentBal`

### 4.4 期末口径

- 继续持有：`netHold = 现金钱包 + 投资钱包 + 公积金 + 自住房估值 − 负债 − 房贷 − 大件分期`。
- 期末卖房：`netSell = 现金钱包 + 投资钱包 + 公积金 + 自住房估值 × (1 − 交易成本%) − 负债 − 房贷 − 大件分期`。
- 不买房时两者相同（房产估值为 0）。

## 5. 输出

1. **结论**：第 N 年末（N = 规划年数）净资产、期末卖房净得（如买房）、资产/负债拆解、住房方案和大件摘要；启用买房时，额外给出同一套参数下"一直租房"的净资产以及买房 − 不买房的差额（两者都按自住房估值计入，不扣卖房成本）；同时给出投资收益率保守/乐观情景下的期末净资产和公积金退休提取额。
2. **每月现金流拆解**：按阶段 1/2/3 各取第一个月，逐项列出月收入、社保、公积金个人、生活开销、房租、房贷、物业、水电和每月净结余；并在下方用一句话写出阶段 1 的完整算式，明确房租已经单独扣除，避免误以为生活开销里已含房租。若勾选"房租优先用公积金余额"，再注明房租先从公积金扣，公积金实际支付额见年度明细。
3. **关键指标**：当前/期末年龄、当前现金/投资/负债、期末现金钱包、投资钱包、公积金、消费负债、房贷、大件分期、自住房估值、净资产、卖房净得、投资钱包和净资产的保守/基准/乐观值、社保累计、公积金累计、累计房租、其中公积金支付房租、退休提取公积金、大件现金支出、房贷利息、大件分期利息、最大总负债、现金钱包最低余额。
4. **资产构成与净资产走势**：堆叠面积图——现金钱包、投资钱包、公积金、自住房估值（面积合计 = 总资产），另用深绿色线画净资产；图下方有颜色说明；标注购房、提前退休、领养老金和大件支出年份；横轴每 10 年显示"年份/年龄"。
5. **投资收益情景**：保守/基准/乐观三行，分别列出投资年化收益率、期末投资钱包、期末净资产；注明这是固定年化情景，不代表真实波动路径。
6. **期末资产拆解表**：当前现金/投资/公积金/负债，期末现金/投资/公积金/房产/负债/房贷/分期，继续持有净资产，卖房净得。
7. **累计收支表**：收入、社保、公积金个人/单位、生活、房租、其中公积金支付房租、房贷、房贷利息、物业、水电、购房首付税费、使用公积金、退休提取公积金、大件首付/一次付清、大件分期还款、大件利息、大件收入、现金钱包利息、投资钱包收益、公积金利息、负债利息。
8. **大件支出明细**：名称、年份、方式、金额、首付/一次付清、贷款、月供、利息。
9. **每年收支与资产明细**：29 列，含年龄、阶段、各项收支、公积金付租、公积金提取、年度现金流、年末现金/投资/公积金/负债、房贷余额、分期余额、房产估值、净资产；购房当年和阶段切换当年高亮。
10. **页面底部说明**：起点口径、社保/公积金口径、公积金退休提取规则、买房启停与卖房成本、大件分期、两个钱包与分阶段每月投资、负债计息、不考虑通胀。

## 6. 校验要求

- **起点**：第 0 年净资产 = 当前现金 + 当前投资 + 当前公积金 − 当前负债。
- **净资产恒等式**：每年 `现金钱包 + 投资钱包 + 公积金 + 房产估值 − 负债 − 房贷余额 − 分期余额 = 净资产`。
- **两个钱包**：初始现金 = 当前现金钱包，初始投资 = 当前投资钱包；现金钱包按现金利率、投资钱包按投资收益率分别计息。
- **结余分配**：正现金流先还负债，剩余进现金钱包；负现金流先取现金钱包，再取投资钱包，最后形成负债。
- **每月拆解**：阶段 1 的"每月净结余"必须等于 `税前月薪 − 社保 − 公积金个人 − 生活开销 − 房租 − 房贷 − 物业 − 水电`；房租必须作为独立一项出现，不能并进生活开销。阶段 2/3 同理，收入分别按 0 和养老金计算。
- **分阶段每月投资**：阶段 1/2/3 各自使用独立的"每月投入投资"金额；每月支出后从现金钱包转入投资钱包，最多不超过现金余额；现金不足时只转能拿出的部分。
- **公积金退休提取**：按"开始退休时 / 领养老金时 / 不提取"设置，在对应月份把公积金余额转入现金钱包；`存款+投资+公积金` 总额不变，年度现金流不变；不提取时公积金继续计息。
- **公积金付房租**：勾选"房租优先用公积金余额"时，当月房租先从公积金余额扣，最多不超过房租；不足部分从现金扣。`fundUsedRent` 计入年度明细，但不计入年度现金流；公积金余额不能为负。
- **内部转移不进现金流**：个人公积金缴存、公积金支付房租、公积金退休提取都不计入年度现金流，只改变钱包构成。
- **投资情景**：保守/基准/乐观分别使用 `期望收益率 − 上下浮动`、期望收益率、`期望收益率 + 上下浮动`；三个情景只改变投资收益率，其余参数相同。
- **社保/公积金只在工作期**：阶段 2/3 的社保、公积金个人、公积金单位列必须为 0。
- **社保/公积金开关**：取消"缴纳社保"后社保列为 0；取消"缴纳公积金"后个人/单位缴存为 0，但已有公积金余额仍按利率计息。
- **社保比例**：工作期社保 = 税前月薪 × 社保比例 × 12（按年汇总）；公积金个人/单位同理，按税前月薪计算。
- **公积金账户**：个人 + 单位缴纳进入公积金；公积金利息按公积金利率累计；期末公积金 = 期初 + 累计个人 + 累计单位 + 累计利息 − 购房使用。
- **购房启停**：勾选"启用买房"才发生购房；取消勾选后房产估值、房贷、物业费均为 0，租金全年支付。
- **购房**：购房月支付首付 + 税费；贷款 = 总价 − 首付；从次月开始还房贷；购房后不再付租金；物业费从次月开始。
- **卖房口径**：卖房净得 = 继续持有净资产 − 房产估值 × 交易成本%。
- **大件一次付清**：金额在第 N 年一次性计入支出。
- **大件分期**：第 N 年付首付，次月起还款；分期结束时余额必须为 0；利息 = 总还款 − 贷款。
- **大件负值**：金额为负时按一次性收入计入，不生成分期。
- **负债**：正现金流先还负债；负债利率填 0 时负债不计息；填正数时按月计息。
- **公积金购房**：勾选时优先用公积金余额；不勾选时公积金余额全部保留到期末。
- **不买房**：房产估值为 0，房贷和物业费为 0，每年都付租金。
- **买房/不买房对比**：启用买房时，自动用同一套参数再跑一次"一直租房"方案；差额 = 买房期末净资产 − 不买房期末净资产，两者都按自住房估值计入。
- **输入边界**：越界值钳制并回写；整数项四舍五入回写；空输入不打断，模型临时使用默认值。
- **极端参数**：各项为 0、阶段禁用、阶段顺序颠倒、投资上下浮动为 0 时不得出现 NaN。

## 7. 非目标

- 通货膨胀、工资增长、租金上涨、物价增长。
- 个税、专项附加扣除、社保缴费基数上下限、公积金缴存基数上下限。
- 社保/公积金缴纳年限对购房资格、公积金贷款额度/利率的影响（房贷利率用综合利率近似）。
- 养老金按缴费年限/缴费基数自动推算；个人养老金账户、企业年金。
- 公积金贷款与商业贷款的分别定价（用综合利率近似）。
- 提前还贷、换房、卖房后再买、以租养贷。
- 房屋维修、翻新、房龄折价、拆迁、产权到期（如需考虑，手动加为大件支出）。
- 多资产组合、资产配置比例、再平衡、单只股票/基金走势；投资钱包只用一个期望年化收益率和上下浮动情景近似。
- 随机波动路径、蒙特卡洛、最大回撤；保守/乐观只是固定年化情景，不是真实路径。
- 投资税费、交易费用、申购赎回费。
- 教育、医疗、赡养等长期专项支出（可手动加为大件支出）。
- 税收、遗产、保险规划。
