# 人生现金流规划（完整建模规范）

> 对应实现：`life-plan.html`。与 `index.html`（买房 vs 租房）、`sell-vs-hold.html`（卖房 vs 留房）通过导航栏互跳。
> 本页是单人 60 年现金流推演，不比较"两条路线"，而是把当前资产、收入阶段、社保公积金、住房选择和大件支出放进同一条时间线。

## 1. 目标

回答这类问题：**以我现在的存款、负债和收入，如果第几年买房、中间买车/装修，社保公积金照缴，60 年后手里大概有多少钱？**

页面支持：

- 当前存款、当前负债、负债利率、存款利率作为起点。
- 工作期 / 提前退休期 / 领养老金期三阶段收入与生活开销。
- 社保个人缴纳、公积金个人 + 单位缴纳、公积金账户余额与利息。
- 住房选择：第 N 年买房，或一直租房。
- 动态添加多项大件支出（买车、装修、婚礼等），支持一次付清或分期。
- 期末同时给出"继续持有房产"和"卖房扣交易成本"两个净资产口径。

## 2. 核心口径

1. **起点不是零。** 第 0 年存款 = 当前存款，公积金 = 当前公积金余额，负债 = 当前负债。第 0 年净资产 = 存款 + 公积金 − 负债。
2. **逐月模拟，周期固定 60 年。** 第 1 年对应月份 1..12，第 N 年对应 `(N−1)×12+1 .. N×12`。
3. **三阶段用年龄表示。** 当前年龄对应第 1 年；第 A 岁落在第 `(A − 当前年龄 + 1)` 年，起始月 = `(A − 当前年龄) × 12 + 1`。阶段 2/3 年龄填 0 表示不启用。
4. **工作期才有工资、社保和公积金。** 阶段 2 无工资无养老金，生活开销从存款里扣；阶段 3 只有养老金，不缴社保公积金。养老金是手填假设值，不按缴费年限自动推算。页面提供"缴纳社保 / 缴纳公积金"开关，取消勾选即视为不缴。
5. **社保个人缴纳是支出，不形成资产。** 社保个人缴纳 = 工资 × 社保个人比例，只在阶段 1 且已开始工作时计列；单位缴纳部分不进入个人现金流。
6. **公积金个人 + 单位缴纳都进入公积金账户。** 公积金账户按公积金年利率按月计息；购房时可选优先用公积金余额支付首付和税费；期末公积金余额计入净资产。取消"缴纳公积金"后不再有新缴存，已有余额仍计息。
7. **住房是选项。**
   - 一直租房：每月付租金 + 水电 + 生活开销，不产生房贷和物业费。
   - 第 M 年买房：购房发生在第 M 年末（月份 M×12）。购房前付租金；购房当月付首付 + 税费（可先用公积金余额）；贷款 = 总价 − 首付；从购房次月起按月等额本息还款，同时开始付物业费；购房后不再付租金。
   - 自住房按"房产年增值率"逐年估值；期末卖房时按"期末卖房交易成本"扣减。
8. **大件支出是动态列表。**
   - 金额 > 0 且分期年数 = 0：第 N 年末一次付清。
   - 金额 > 0 且分期年数 > 0：第 N 年末付首付，剩余部分从次月起按等额本息分期，利息计入成本。
   - 金额 < 0：第 N 年末按一次性收入处理（如卖旧车、家人资助），不做分期。
9. **资金分配规则。** 每月现金流为正时先还负债，还清后才进存款；现金流为负时先取存款，存款不足的部分形成负债。存款按存款利率、公积金按公积金利率、负债按负债利率分别按月滚动。
10. **期末净资产 = 存款 + 公积金 + 自住房估值 − 负债 − 房贷余额 − 大件分期余额。**
11. **年度现金流**（用于年度明细）= 收入 + 单位公积金 + 存款利息 + 公积金利息 − 社保 − 生活开销 − 房租 − 房贷月供 − 物业费 − 水电燃气取暖 − 大件支出 − 购房首付税费 − 负债利息。
    - 个人公积金是工资到公积金账户的内部转移，不计入年度现金流；单位公积金是额外进入公积金账户的钱。
12. **不考虑通货膨胀、工资增长、租金上涨、房屋维修与翻新。** 所有收入、租金、开销都是固定值；维修/翻新如需考虑，请手动添加为大件支出。

## 4. 计算逻辑

### 4.1 每月顺序

对 t = 1..60×12：

1. 判定阶段，得到月收入 `inc`、月生活开销 `liv`、是否处于工作期。
2. 存款计息：`deposit += deposit × 存款月利率`。
3. 公积金计息：`fund += fund × 公积金月利率`。
4. 负债计息：`debt += debt × 负债月利率`。
5. 工作期社保/公积金：`social = inc × 社保比例`，`fundP = inc × 公积金个人比例`，`fundE = inc × 公积金单位比例`；`fund += fundP + fundE`。
6. 房贷：购房次月起，按等额本息还款，利息 = 剩余本金 × 房贷月利率；最后一个月强制还清剩余本金。
7. 大件分期：购房/购买次月起还款；最后一个月强制还清剩余本金。
8. 购房月：`首付 + 税费` 先从公积金余额扣（若启用），剩余从存款扣；不足部分形成负债；贷款余额 = 总价 − 首付。
9. 计算当月现金流：
   `flow = inc − social − fundP − liv − 房租 − 房贷 − 物业 − 水电 − 大件支出 − 购房现金支出 + 大件负值收入`
10. 资金分配：
    - `flow ≥ 0`：先还负债，剩余进存款。
    - `flow < 0`：先取存款，不足部分形成负债。

### 4.2 阶段判定

- 阶段 3 优先：`t ≥ 领养老金起始月` → 阶段 3。
- 阶段 2 次之：`t ≥ 提前退休起始月` → 阶段 2。
- 否则阶段 1。
- 早于开始工作月：无收入、无生活开销、无社保公积金。
- 阶段顺序颠倒（p2 > p3）时以更早的边界为准，阶段 2 被跳过。

### 4.3 年度快照

每年末记录：

- 收入、社保、公积金个人/单位、生活、房租、房贷、物业、水电、大件、购房、利息收入、公积金利息、负债利息。
- 年度现金流、年末存款、年末公积金、年末负债、房贷余额、大件分期余额、房产估值、净资产。

其中净资产：

`deposit + fund + houseValue − debt − mortgageBal − installmentBal`

### 4.4 期末口径

- 继续持有：`netHold = 存款 + 公积金 + 自住房估值 − 负债 − 房贷 − 大件分期`。
- 期末卖房：`netSell = 存款 + 公积金 + 自住房估值 × (1 − 交易成本%) − 负债 − 房贷 − 大件分期`。
- 不买房时两者相同（房产估值为 0）。

## 5. 输出

1. **结论**：第 60 年末净资产、期末卖房净得（如买房）、资产/负债拆解、住房方案和大件摘要；选择买房时，额外给出同一套参数下"一直租房"的净资产以及买房 − 不买房的差额（两者都按自住房估值计入，不扣卖房成本）。
2. **关键指标**：当前/期末年龄、当前存款/负债、期末存款、公积金、消费负债、房贷、大件分期、自住房估值、净资产、卖房净得、社保累计、公积金累计、大件现金支出、房贷利息、大件分期利息、最大总负债、最低现金余额。
3. **资产走势**：三条线——净资产（含房产）、现金+公积金−消费负债、自住房估值；标注购房、提前退休、领养老金和大件支出年份；横轴每 10 年显示"年份/年龄"。
4. **期末资产拆解表**：当前存款/公积金/负债，期末存款/公积金/房产/负债/房贷/分期，继续持有净资产，卖房净得。
5. **累计收支表**：收入、社保、公积金个人/单位、生活、房租、房贷、房贷利息、物业、水电、购房首付税费、使用公积金、大件首付/一次付清、大件分期还款、大件利息、大件收入、存款利息、公积金利息、负债利息。
6. **大件支出明细**：名称、年份、方式、金额、首付/一次付清、贷款、月供、利息。
7. **每年收支与资产明细**：25 列，含年龄、阶段、各项收支、年度现金流、年末存款/公积金/负债、房贷余额、分期余额、房产估值、净资产；购房当年和阶段切换当年高亮。
8. **页面底部说明**：起点口径、社保/公积金口径、买房选项与卖房成本、大件分期、负债计息、不考虑通胀。

## 6. 校验要求

- **起点**：第 0 年净资产 = 当前存款 + 当前公积金 − 当前负债。
- **净资产恒等式**：每年 `存款 + 公积金 + 房产估值 − 负债 − 房贷余额 − 分期余额 = 净资产`。
- **社保/公积金只在工作期**：阶段 2/3 的社保、公积金个人、公积金单位列必须为 0。
- **社保/公积金开关**：取消"缴纳社保"后社保列为 0；取消"缴纳公积金"后个人/单位缴存为 0，但已有公积金余额仍按利率计息。
- **社保比例**：工作期社保 = 工资 × 社保比例 × 12（按年汇总）。
- **公积金账户**：个人 + 单位缴纳进入公积金；公积金利息按公积金利率累计；期末公积金 = 期初 + 累计个人 + 累计单位 + 累计利息 − 购房使用。
- **购房**：购房月支付首付 + 税费；贷款 = 总价 − 首付；从次月开始还房贷；购房后不再付租金；物业费从次月开始。
- **卖房口径**：卖房净得 = 继续持有净资产 − 房产估值 × 交易成本%。
- **大件一次付清**：金额在第 N 年一次性计入支出。
- **大件分期**：第 N 年付首付，次月起还款；分期结束时余额必须为 0；利息 = 总还款 − 贷款。
- **大件负值**：金额为负时按一次性收入计入，不生成分期。
- **负债**：正现金流先还负债；负债利率填 0 时负债不计息；填正数时按月计息。
- **公积金购房**：勾选时优先用公积金余额；不勾选时公积金余额全部保留到期末。
- **不买房**：房产估值为 0，房贷和物业费为 0，每年都付租金。
- **买房/不买房对比**：选择买房时，自动用同一套参数再跑一次"一直租房"方案；差额 = 买房期末净资产 − 不买房期末净资产，两者都按自住房估值计入。
- **输入边界**：越界值钳制并回写；整数项四舍五入回写；空输入不打断，模型临时使用默认值。
- **极端参数**：各项为 0、阶段禁用、阶段顺序颠倒时不得出现 NaN。

## 7. 非目标

- 通货膨胀、工资增长、租金上涨、物价增长。
- 个税、专项附加扣除、社保缴费基数上下限、公积金缴存基数上下限。
- 社保/公积金缴纳年限对购房资格、公积金贷款额度/利率的影响（房贷利率用综合利率近似）。
- 养老金按缴费年限/缴费基数自动推算；个人养老金账户、企业年金。
- 公积金贷款与商业贷款的分别定价（用综合利率近似）。
- 提前还贷、换房、卖房后再买、以租养贷。
- 房屋维修、翻新、房龄折价、拆迁、产权到期（如需考虑，手动加为大件支出）。
- 股票、基金、理财等风险资产配置；存款利率为唯一理财收益。
- 教育、医疗、赡养等长期专项支出（可手动加为大件支出）。
- 税收、遗产、保险规划。
