# 买房 VS 租房：N 年后手上现金对比模型（完整提示词 / 建模规范）

> 本文件是给开发者或 AI 的完整需求说明。界面已在 `index.html` 实现。
> 旧文件 `房租对比计算器-spec.md` 已过时，以本文件为准。

## 1. 目标

比较同一个人在两种住房选择下，**第 N 年末（默认 30 年）手上到底有多少钱**：

- 路线 A：买房。从零开始攒钱，攒够"首付 + 购房税费"后购房；购房前和租房者一样租房生活；购房后按揭还款，装修，可能临时租房，期末卖房或自住。
- 路线 B：租房。从零开始，每月付租金，每月存下结余，期末手上只有存款。

同一个人、两种选择。收入、生活开销、水电燃气取暖、其他人生事件及其发生时点完全一致。

## 2. 核心口径

1. **两人都从零开始。** 买房者和租房者期初现金都是 0。
2. **买房者先攒钱，攒够再买房。** 购房前，买房者与租房者的收支完全相同（都付租金、生活开销、水电燃气取暖，都把结余存入银行）。当买房者的存款 ≥ 购房所需（首付 + 购房税费）且无负债时，在该月末购房，一次性支出首付和税费。
3. **购房时间不固定。** 由攒钱速度决定，可能在对比周期内，也可能超出对比周期（此时买房者未购房，结果与租房者相同）。
4. **购房税费。** 契税、印花税等按总价的比例计算（默认 1.5%），与首付一起在购房月支出。
5. **购房价格。** 购房时的房价取当前总价 P0，不随时间变化（v1 假设）。
6. **购房后月度支出。** 月供、装修分期、物业费、水电燃气取暖、生活开销、临时租房（如有）。购房后不再付租金，但装修期间的临时租房按月付租金。
7. **装修费无利息分期。** 装修费总额按装修还款年限等额按月偿还，无利息，从购房后第 1 个月开始。
8. **翻新费在购房后第 X 年末发生。** X 从购房月起算，默认 30 年，即购房后第 30 年末作为现金支出计入当月现金流。若该时点超出对比周期 N，则不计入。
9. **存款规则。** 正余额按年化存款利率（默认 1.3%）按月计息，月利率 = 年利率 / 12，结余月末入账。存款无利息税。
10. **现金不足时的负债。** 若某月现金流为负且存款不足，差额记为负债，负债不计利息，不复利。之后正现金流先还负债，还清后才累计存款。
11. **房贷按约定期限还，不提前还。** 从购房后第 1 个月起按等额本息还款。
12. **期末方式二选一。** 默认"期末卖房"：卖房所得 = 期末房价 − 剩余贷款余额。可切换为"不卖房"：房产估值不计入现金，但仍需偿还剩余贷款。卖房交易成本（税费、中介费）不纳入计算，仅在页面底部提示。
13. **对比周期与贷款期限独立。** 贷款结束后买房者不再支付月供，月结余增加。

> 装修费无利息、未计入贷款利息，结果仅供参考。

## 4. 计算逻辑（逐月）

令 t = 1..N×12，i = 存款年利率 / 12，r = 房贷年利率 / 12。购房所需 T = P0 × 首付比例 + P0 × 购房税费比例。

**初始（t = 0）**

- 两人现金 S = 0，负债 D = 0，未购房。

**购房前（未购房时，买房者与租房者相同）**

- 每月净现金流 F = 收入 − 租金 − 水电燃气取暖 − 生活开销
- S = S × (1+i)，再按现金流分配（见下）
- 若 D = 0 且 S ≥ T：S −= T，标记购房月 = t，买房者转入购房后阶段

**购房后（买房者，t > 购房月）**

- k = t − 购房月
- 贷款：贷款额 = P0 × (1 − 首付比例)，月供 M 按等额本息，期数 = 贷款年限 × 12。若 k ≤ 贷款期数：Bal = Bal × (1+r) − M，下限 0
- 装修分期：dp = 装修费 / (装修还款年限 × 12)，若 k ≤ 装修还款期数：Dec −= dp，下限 0
- 临时租房：若 k ≤ 临时租房月数：支付租金
- 翻新：若 k = X × 12：支出翻新费
- 每月净现金流 F = 收入 − (k ≤ 贷款期数 ? M : 0) − (k ≤ 装修还款期数 ? dp : 0) − (k = X × 12 ? 翻新费 : 0) − 物业费 − 水电燃气取暖 − 生活开销 − (k ≤ 临时租房月数 ? 租金 : 0)
- S = S × (1+i)，再按现金流分配

**现金流分配（两人共用规则）**

- 若 F ≥ 0：先还负债 repay = min(D, F)，D −= repay，S += F − repay
- 若 F < 0：先从存款支取 take = min(S, −F)，S −= take，D += (−F − take)

**租房者每月**

- 与购房前相同：F = 收入 − 租金 − 水电燃气取暖 − 生活开销，计息后按上述规则分配。

**期末（t = N×12）**

- 若未购房：买房者手上现金 = S − D（无房产、无贷款）
- 若已购房：买房者手上现金 = S − D + 房产变现值 − Bal − Dec
  - 房产变现值：期末卖房时为 F；不卖房时为 0
  - 翻新费已在其发生月计入 S
- 租房者手上现金 = S − D
- 差额 = 买房者 − 租房者

**中间年份**（用于画走势）

- 每年末记录两条路线的"手上现金" = 存款 − 负债。
- 买房者未购房时，现金等于租房者现金。
- 购房后，中间年份只计现金，不计房屋价值、剩余贷款和未还清的装修费（这些只在期末计入）。

## 5. 输出

1. **结论**：`N 年后，买房者手上现金 X 万元，租房者手上现金 Y 万元。买房比租房【多/少】 Z 万元。` 若未购房，改为说明买房者攒不够首付。
2. **期末扣款框**（结果区顶部）：显示期末未还清的装修费；说明翻新费是否在对比周期内发生；注明装修费无利息。未购房时显示"无期末扣款"。
3. **关键指标**：每月月供（购房后）、购房所需（首付 + 税费）、买房时间（约 X 年后）、购房后每月结余、租房每月结余、交叉点。
4. **走势图**：横轴年份 0..N，两条线；现金为负时显示为负值；标出首次交叉年份（若有）。
5. **成本拆解**：
   - 买房：首付、购房税费、购房前租金合计、临时租房合计、月供合计、装修费合计、物业费合计、水电燃气取暖合计、生活开销合计、翻新费、期末未还清的装修费、期末负债、期末剩余贷款。
   - 租房：租金合计、水电燃气取暖合计、生活开销合计。
6. **每年收支明细表**（页面最下方，买房与租房各一张）：每行一年，列出各项支出、存款利息、年度结余（收入 + 利息 − 支出）、年末存款、年末负债、年末现金。单位为元。
7. **页面底部提示**（必须显示）：
   - `两人都从零开始攒钱。买房者攒够"首付 + 购房税费"后购房，购房前与租房者生活支出相同。`
   - `装修费无利息，按装修费还款年限等额按月偿还。现金不足时形成的负债同样不计利息，结果仅供参考。`
   - `卖房时的交易成本（税费、中介费等）未计入计算，实际卖房时可能需要另行考虑。`

## 6. 校验要求

- **起点**：两人期初现金均为 0。
- **购房前一致**：购房前两条路线的现金流完全相同，年度现金曲线重合。
- **购房条件**：购房月末存款 ≥ 首付 + 税费，且无负债。
- **负债不复利**：负债在无现金流时保持不变，正现金流先还负债。
- **翻新**：只在购房后第 X 年所在月扣除；购房后时点超过 N 时不扣。
- **未购房**：若 N 年内攒不够，买房者结果等于租房者结果。
- **对比周期超过贷款期限**：贷款结束后买房者月结余应增加，不出现负的月供。
- **极端参数**：购房税费 = 0、装修费 = 0、临时租房 = 0、翻新费 = 0、水电 = 0 时，结果应只受首付、月供和租金的差异影响。

## 7. 非目标（v1 不做）

- 收入、租金、房价、水电、物业费的年增长率（对比周期较长时，固定值会偏离现实，列为 v2）。
- 购房前房价随时间变化（v1 假设购房价格固定为 P0）。
- 利息税、增值税、个税、中介费等卖房交易成本（仅页面提示，不计算）。
- 提前还贷策略、公积金、组合理财产品。
- 装修费或负债的利息（按约定不计利息）。
- 押金、租房中介费、搬家费、家具家电购置（待你确认是否加入）。

## 8. 待确认事项

- 购房税费比例默认 1.5%，需要根据面积和首套/二套确认。
- 临时租房月数默认 3 个月，水电燃气取暖默认 300 元/月，都是假设值。
- 购房价格是否随时间变化（攒钱期间房价上涨或下跌）。
