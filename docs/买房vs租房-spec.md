# 买房 VS 租房：N 年后手上现金对比模型（完整提示词 / 建模规范）

> 本文件是给开发者或 AI 的完整需求说明。界面已在 `index.html` 实现。
> 旧文件 `房租对比计算器-spec.md` 已过时，以本文件为准。

## 1. 目标

比较同一个人在两种住房选择下，**第 N 年末（固定 60 年）手上到底有多少钱**：

- 路线 A：买房。在**设定年份**购房（用户直接选第几年买）；购房前和租房者一样租房生活；购房后按揭还款，装修，可能临时租房，期末卖房或自住。
- 路线 B：租房。从零开始，每月付租金，每月存下结余，期末手上只有存款。

同一个人、两种选择。收入、生活开销、水电燃气取暖、其他人生事件及其发生时点完全一致。

## 2. 核心口径

1. **两人都从零开始。** 买房者和租房者期初现金都是 0。
2. **购房年份由用户指定（v2 改动）。** 独立的"第几年购房"输入框，取值 1～60，默认第 10 年。购房时点不再由"攒钱速度"决定。
3. **不限制购房时的自有资金（v2 改动）。** 首付 + 税费一次付清；付不出来的部分自动转为负债（不计息、不复利）。这允许"借钱买房"的场景被真实建模。
4. **购房前的现金流。** 购房前，买房者与租房者的收支完全相同（都付租金、生活开销、水电燃气取暖，都把结余存入银行）。
5. **购房税费。** 契税、印花税等按总价的比例计算（默认 1.5%），与首付一起在购房月支出。
6. **购房价格。** 购房时的房价取当前总价 P0，不随时间变化（v1 假设）。
7. **购房后月度支出。** 月供、装修分期、物业费、水电燃气取暖、生活开销、临时租房（如有）。购房后不再付租金，但装修期间的临时租房按月付租金。
8. **装修费无利息分期。** 装修费总额按装修还款年限等额按月偿还，无利息，从购房后第 2 个月开始（购房当月只计期初总额，不偿还）。
9. **翻新费在购房后第 X 年末发生。** X 从购房月起算，默认 30 年，即购房后第 30 年末作为现金支出计入当月现金流。若该时点超出对比周期 N，则不计入。
10. **存款规则。** 正余额按年化存款利率（默认 1.3%）按月计息，月利率 = 年利率 / 12，结余月末入账。存款无利息税。
11. **现金不足时的负债。** 若某月现金流为负且存款不足，差额记为负债，负债不计利息，不复利。之后正现金流先还负债，还清后才累计存款。
12. **房贷按约定期限还，不提前还。** 从购房后第 1 个月起按等额本息还款。
13. **期末方式二选一。** 默认"期末卖房"：卖房所得 = 期末房价 − 剩余贷款余额。可切换为"不卖房"：房产估值不计入现金，但仍需偿还剩余贷款。卖房交易成本（税费、中介费）不纳入计算，仅在页面底部提示。
14. **对比周期固定为 60 年。** 不再是输入项。贷款年限、装修还款年限超过剩余周期时，超出部分不产生支出，但期末负债照实保留。
15. **三阶段收入/开销模型（v4 改动）。** 个人收入按三个阶段划分，界面上在"个人与理财参数"卡片里用三个子框分组：
    - **阶段 1 工作期**：月收入 = 每月工作收入，无养老金。起始年龄默认 = 当前年龄。
    - **阶段 2 提前退休期**：**没有工资，也没有养老金**，生活开销全部从已有存款里扣（先吃利息，再吃本金），存款不够就记为透支欠款。年龄填 0 表示不启用。
    - **阶段 3 领养老金期**：月收入 = 每月养老金，无工资。年龄填 0 表示不启用。
    - 阶段 2/3 未启用时，阶段 1 一直持续到期末。
    - **每个阶段各自填一份"每月其他生活开销"**，三份互相独立。
    - **没有独立的"理财提取"参数**：阶段 2 的开销花的就是存款本身，不存在"提取"与"开销"两笔账。早期版本曾有一个"每月从理财提取"字段，会导致开销被扣两次（既扣一次开销、又扣一次提取），已删除。
    - 阶段划分对买房者和租房者是同一个人的共同事件，两条路线用同一套参数。
16. **阶段用"年龄"表示（v5 改动）。** 以「当前年龄」为锚点：
    - **当前年龄** `currentAge`（默认 25 岁）：对应第 1 年。
    - **第 A 岁落在第 (A − currentAge + 1) 年**，起始月 = (A − currentAge) × 12 + 1。
    - 默认：当前 25 岁、55 岁提前退休、65 岁领养老金 → 分别落在第 1 年、第 31 年、第 41 年。
    - 第 N 年的年末年龄 = currentAge + N − 1，所以第 60 年末 = 25 + 60 − 1 = **84 岁**（起点第 0 年标当前年龄 25 岁）。
    - 购房年份仍用"第几年"表示（第 1～60 年），不随年龄变化。

> 装修费无利息、未计入贷款利息，结果仅供参考。

## 4. 计算逻辑（逐月）

令 t = 1..N×12（N = 60 年固定），i = 存款年利率 / 12，r = 房贷年利率 / 12。购房所需 T = P0 × 首付比例 + P0 × 购房税费比例。购房月 M = 购房年份 × 12。

**阶段判定**

- 第 N 年对应月份 (N−1)×12+1 .. N×12
- **年龄 → 起始月**：`起始月 = (A − currentAge) × 12 + 1`，即"第 A 岁"落在第 (A − currentAge + 1) 年
- 起始年龄填 0 表示该阶段不启用（起始月 = ∞）
- 第 t 个月的阶段 ph：
  - t ≥ M3 → 阶段 3（领养老金）
  - t ≥ M2 → 阶段 2（提前退休）
  - 否则 → 阶段 1（工作期）
- 若 t < M1，尚未开始工作：**无收入、无开销**
- 月收入 `inc(ph)`：阶段1 = 每月工作收入；阶段2 = 0；阶段3 = 每月养老金
- 月生活开销 `liv(ph)`：三个阶段各自独立取值
- **年末年龄** = currentAge + N − 1（第 0 年即起点标 currentAge）

**阶段 2 的资金来源（关键）**

阶段 2 没有收入，所以开销的钱**只能从存款里出**——这正是负现金流 `applyFlow` 的既有行为：

- 每月现金流 F = −(租金 + 水电 + 生活开销) < 0
- `applyFlow` 先从存款支取 `take = min(S, −F)`，S 减少
- 存款不足的部分记为透支欠款 D（不计息）

因此阶段 2 不需要额外的"理财提取"参数：**开销花的就是存款**，先吃利息、再吃本金、最后欠债。
早期版本曾把"每月从理财提取"当作独立收入项，导致开销被扣两次，已删除。

**初始（t = 0）**

- 两人现金 S = 0，负债 D = 0，未购房。

**购房前（t < M，买房者与租房者相同）**

- 每月净现金流 F = inc(ph) − 租金 − 水电燃气取暖 − liv(ph)
- S = S × (1+i)，再按现金流分配（见下）

**购房月（t = M）**

- 一次性支出首付 + 税费：S, D = 分配(S, D, −T)
  - 现金不足时，T 超出 S 的部分直接转为负债 D（不计息），因此允许"借钱买房"
- 装修费按期初总额计入负债余额（`decorBal = 装修费`），由后续月度结余等额偿还，无利息

**购房后（t > M，买房者）**

- k = t − M
- 贷款：贷款额 = P0 × (1 − 首付比例)，月供 P 按等额本息，期数 = 贷款年限 × 12。若 k ≤ 贷款期数：Bal = Bal × (1+r) − P，下限 0
- 装修分期：dp = 装修费 / (装修还款年限 × 12)，若 1 ≤ k ≤ 装修还款期数：Dec −= dp，下限 0
- 临时租房：若 k ≤ 临时租房月数：支付租金
- 翻新：若 k = X × 12：支出翻新费
- 每月净现金流 F = inc(ph) − (k ≤ 贷款期数 ? P : 0) − (1 ≤ k ≤ 装修还款期数 ? dp : 0) − (k = X × 12 ? 翻新费 : 0) − 物业费 − 水电燃气取暖 − liv(ph) − (k ≤ 临时租房月数 ? 租金 : 0)
- S = S × (1+i)，再按现金流分配

**现金流分配（两人共用规则）**

- 若 F ≥ 0：先还负债 repay = min(D, F)，D −= repay，S += F − repay
- 若 F < 0：先从存款支取 take = min(S, −F)，S −= take，D += (−F − take)

**租房者每月**

- 与购房前相同：F = inc(ph) − 租金 − 水电燃气取暖 − liv(ph)，计息后按上述规则分配。

**期末（t = N×12）**

- 若未购房（购房年份超出周期，实际不会发生）：买房者手上现金 = S − D（无房产、无贷款）
- 若已购房：买房者手上现金 = S − D + 房产变现值 − Bal − Dec
  - 房产变现值：期末卖房时为 F；不卖房时为 0
  - 翻新费已在其发生月计入 S
- 租房者手上现金 = S − D
- 差额 = 买房者 − 租房者

**中间年份**（用于画走势）

- 每年末记录两条路线的"手上现金" = 存款 − 负债，以及当年所处的阶段 ph。
- 买房者未购房时，现金等于租房者现金。
- 购房后，中间年份只计现金，不计房屋价值、剩余贷款和未还清的装修费（这些只在期末计入）。

**辅助指标**

- 购房当年末负债 `debtAtBuy`：购房年份那一行的年末负债，直接反映"当年借钱买了多少"
- 周期内最大负债 `peakDebt`：所有年份里负债的最大值，反映最紧张的时刻
- 各阶段月结余 `surplusP1/P2/P3`：取"阶段开始、且已购房"的月份作为代表，按该月贷款/装修是否仍在偿还计算，供关键指标展示。阶段 3 若贷款已还清，不得再扣月供与装修分期；若整个阶段都在购房前，买房者结余与租房者相同，页面标注"购房前，与租房相同"。

**默认口径（v4）**

- 期末方式默认 **不卖房**（自住到期末），房产估值不计入现金。

## 5. 输出

1. **结论**：`N 年后（<期末年龄> 岁），买房者手上现金 X 万元，租房者手上现金 Y 万元。买房比租房【多/少】 Z 万元。` 并标注购房年份；若购房当年自有资金不足，额外提示当年形成的负债金额；若启用了阶段 2/3，用一句话串起三个阶段的起止年龄与收入。页面副标题也显示"现年 X 岁…第 60 年末（Y 岁）"。
2. **期末扣款框**（结果区顶部）：显示期末未还清的装修费；说明翻新费是否在对比周期内发生；注明装修费无利息。未购房时显示"无期末扣款"。
3. **关键指标**：每月月供（购房后）、购房所需（首付 + 税费）、购房年份、当前年龄，再按启用的阶段追加——阶段1 开始工作年龄/工作月收入/买房月结余/租房月结余、阶段2 提前退休年龄/买房月结余/租房月结余、阶段3 领养老金年龄/每月养老金/买房月结余/租房月结余，最后是交叉点、购房当年末负债、周期内最大负债、期末负债、期末剩余贷款。

7. **页面底部提示**（必须显示）：
   - `买房者在设定年份购房，购房前与租房者生活支出相同。不限制购房时的自有资金——首付、税费和装修费付不出来的部分会自动记为负债（负债不计息、不复利）。`
   - `装修费在购房时一次付清，随后按装修费还款年限无息分期偿还。现金不足时形成的负债同样不计利息，结果仅供参考。`
   - `对比周期固定为 60 年。贷款年限、装修还款年限超过 60 年的部分不会产生支出，期末负债照实保留。`
   - `个人收入分三个阶段——① 工作期（有工资）；② 提前退休期（无工资无养老金）；③ 领养老金期（有养老金无工资）。三个阶段各自填一份"每月其他生活开销"，年龄填 0 表示该阶段不启用。`
   - `阶段用年龄表示。「当前年龄」对应第 1 年，所以第 A 岁落在第 (A − 当前年龄 + 1) 年。默认当前 25 岁、55 岁提前退休、65 岁领养老金，分别对应第 1 年、第 31 年、第 41 年。`
   - `提前退休期不领工资也不领养老金，生活开销直接从已有存款里扣（先吃利息，再吃本金），存款不够就记为透支欠款。没有额外的"理财提取"——开销花的就是存款。`
   - `养老金不随时间增长，也未计入社保调整与通货膨胀。阶段划分对买房者和租房者是同一个人的共同事件。`
   - `卖房时的交易成本（税费、中介费等）未计入计算，实际卖房时可能需要另行考虑。`

## 6. 校验要求

- **起点**：两人期初现金均为 0。
- **购房前一致**：购房前两条路线的现金流完全相同，年度现金曲线重合。
- **购房时点固定**：第 M 月 = 购房年份 × 12 发生购房，与攒钱速度无关。
- **允许负债**：购房当年现金不足以支付首付 + 税费时，差额计入负债；页面显示当年末负债金额。
- **负债不复利**：负债在无现金流时保持不变，正现金流先还负债。
- **装修分期**：从购房次月（k=1）开始按月偿还，购房当月不偿还；装修费总额在 decorYears × 12 个月内还清。
- **翻新**：只在购房后第 X 年所在月扣除；购房后时点超过 N 时不扣。
- **年龄换算**：第 A 岁必须落在第 (A − 当前年龄 + 1) 年，前一年仍是上一阶段；不能提前一整年。
- **默认场景**：当前 25 岁 / 55 岁退休 / 65 岁领养老金 → 第 1 / 31 / 41 年。
- **期末年龄**：第 N 年末年龄 = 当前年龄 + N − 1；默认 25 + 60 − 1 = 84 岁（不是 85）。
- **改变当前年龄**：三个阶段对应的年份应同步平移（当前 30 岁 → 55 岁在第 26 年、65 岁在第 36 年）。
- **阶段2 无收入**：提前退休期的收入列必须为 0，养老金不出现。
- **阶段2 资金来源**：阶段 2 净现金必须逐年下降（吃利息 → 吃本金 → 转负债）；不得出现"提取"这种第二笔扣款。
- **阶段2 单调性**：阶段 2 的生活开销越大，期末现金越差（不得出现开销越大反而越富）。
- **阶段3 有养老金无工资**：领养老金期收入 = 12 × 每月养老金。
- **阶段结余不重复扣已还清的贷款**：贷款已还清的阶段，其"买房月结余"不得再扣月供与装修分期。默认场景（第 10 年购房、30 年贷款）阶段 3 应从第 41 年开始，此时贷款已还清，买家月结余 = 养老金 − 物业费 − 水电 − living3。
- **购房前阶段**：若某阶段完全在购房年份之前，买家尚未持有房产，该阶段"买房月结余"应等于租房月结余，页面标注"购房前，与租房相同"。
- **阶段年龄 = 0**：该阶段不启用，阶段判定跳过它。
- **阶段顺序颠倒（p2 > p3）**：以更早的阶段边界为准，不报错、不出现 NaN。
- **阶段顺序相同（p2 = p3）**：阶段2 被跳过。
- **三份开销独立**：改 living1 / living2 / living3 各自只影响对应阶段的开销列。
- **阶段1 起始年龄 > 当前年龄**：该年之前无收入无开销。
- **恒等式**：所有年份 deposit − debt == cash；年度结余 == 收入 + 利息 − 支出。
- **输入边界**：所有数值输入越界时钳制到各自范围并立即回写输入框；整数项四舍五入后回写；空输入不打断用户输入，模型临时使用默认值。购房年份钳制到 [1, 60]，年龄钳制到 [0, 120]，当前年龄钳制到 [1, 100]。
- **对比周期固定 60**：贷款年限、装修还款年限超过剩余周期时，超出部分不产生支出。
- **极端参数**：各项为 0 时不得出现 NaN。
- **期末默认不卖房**：首次加载时"不卖房"为默认口径。

## 7. 非目标（v1 不做）

- 收入、租金、房价、水电、物业费的年增长率（对比周期较长时，固定值会偏离现实，列为 v2）。
- 购房前房价随时间变化（v1 假设购房价格固定为 P0）。
- 利息税、增值税、个税、中介费等卖房交易成本（仅页面提示，不计算）。
- 提前还贷策略、公积金、组合理财产品。
- 装修费或负债的利息（按约定不计利息）。
- 押金、租房中介费、搬家费、家具家电购置（待你确认是否加入）。
- 养老金逐年增长、社保调整、通胀（养老金按固定值计算）。
- 个人养老金账户（已有余额 + 每月定投 + 退休提取）——目前只建模基础养老金这一条现金流。
- 退休后医疗支出、养老机构费用等特殊支出。
- 阶段2 的理财收益来自独立理财账户（目前只按存款年化利率计息，不区分"提前退休理财"和"存款"）。
- 阶段1 中途换工作、收入跳变等事件（工资在整个阶段1 是固定值）。
- 阶段2 的"每月固定提取额"（已删除该参数：开销花的就是存款，不需要单独提取）。

## 8. 待确认事项

- 购房税费比例默认 1.5%，需要根据面积和首套/二套确认。
- 临时租房月数默认 3 个月，水电燃气取暖默认 300 元/月，都是假设值。
- 购房价格是否随时间变化（攒钱期间房价上涨或下跌）。
- 三阶段默认值：当前年龄 25 岁、25 岁开始工作（月工资 6000 元、开销 2000 元）、55 岁提前退休、65 岁领养老金（月养老金 3000 元）；阶段2/3 的开销默认 2000 元。
- 是否需要按性别/缴费年限自动估算养老金金额（默认 3000 元/月是假设值）。
- 是否需要"首付额外借入"（如父母资助、消费贷）与"负债计息"两个更细的口径。
- 个人养老金账户是否要建模。
